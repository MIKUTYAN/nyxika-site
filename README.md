# nyxika — сайт + адмінка

Тека готова до заливки на **Netlify**. Усередині:

```
index.html        сам сайт
img/              усі картинки
data/             вміст, який редагується через адмінку
  works.json        персонажі, фони, half-body
  pricing.json      тарифи й доповнення
  reviews.json      відгуки покупців
admin/            адмінка
  index.html
  config.yml        ← тут треба замінити один рядок
```

---

## 1. Репозиторій на GitHub

1. Створи новий репозиторій, назви його наприклад `nyxika-site`. Можна **Private** — адмінка працює і з приватним.
2. Залий туди **вміст цієї теки** (щоб `index.html` лежав у корені репозиторію, а не всередині ще однієї папки).

## 2. Підключити Netlify

1. Netlify → **Add new site** → **Import an existing project** → GitHub → обери свій репозиторій.
2. Build command — **залиш порожнім**. Publish directory — теж порожнє або крапка `.`
3. **Deploy**. Через хвилину сайт буде на `щось.netlify.app`.

## 3. Прописати свій репозиторій в адмінці

Відкрий `admin/config.yml`, перший рядок:

```yaml
repo: YOUR-GITHUB-USERNAME/nyxika-site
```

Заміни на свої реальні дані, наприклад `nyxika/nyxika-site`. Збережи, закоміть.
Якщо гілка називається `master`, а не `main` — поміняй і рядок `branch`.

## 4. Вхід в адмінку

Адмінка живе за адресою `твій-сайт.netlify.app/admin/`.

### Спосіб А — швидкий, без зайвих налаштувань

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Repository access: **Only select repositories** → твій репозиторій.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. Згенеруй, скопіюй токен (показується один раз).
5. Відкрий `/admin/`, натисни **Sign In with Token**, встав токен.

Токен лишається у твоєму браузері. На новому пристрої доведеться вставити знову.

### Спосіб Б — постійний вхід кнопкою «Sign in with GitHub»

1. GitHub → Settings → Developer settings → **OAuth Apps** → **New OAuth App**
   - Homepage URL: адреса твого сайту
   - Authorization callback URL: `https://api.netlify.com/auth/done`
2. Скопіюй **Client ID**, згенеруй **Client Secret**.
3. Netlify → **Project configuration** → **Security** → **OAuth** (саме OAuth, **не** Identity) → **Install provider** → GitHub → встав Client ID і Secret.

Після цього на `/admin/` працюватиме звичайна кнопка входу, і заходити можна буде з будь-якого пристрою, зокрема з телефона.

> **Не вмикай Netlify Identity та Git Gateway.** Git Gateway задеприкейчено, старі інструкції в інтернеті ведуть саме туди і більше не працюють.

## Як це працює

Натискаєш **Publish** в адмінці → вона робить коміт у репозиторій → Netlify бачить коміт і сам перезбирає сайт. Через 30–60 секунд зміни в ефірі.

## Що можна редагувати

| Розділ | Що саме |
|---|---|
| **Роботи** | Додати / видалити / перейменувати персонажів, фони та half-body. Перетягуванням змінити порядок. Галочка **«Показати на головній»** вирішує, які три картки видно на першій сторінці. |
| **Ціни** | Суми в усіх чотирьох тарифах, список доповнень, відсоток за комерційні права. |
| **Відгуки** | Текст відгуку і нік покупця. |

## Картинки

Кожна робота має **дві** картинки:

- **Картка** — те, що видно в сітці. Персонажі й half-body: вертикальна **3:4** (близько 800×1066). Фони: горизонтальна **16:10** (близько 900×562).
- **Повний лист** — відкривається по кліку. Найдовша сторона близько **1400 px**.

Завантажені через адмінку картинки самі лягають у теку `img/`.

**ID** у кожної роботи має бути унікальним, латиницею, без пробілів. Він ні на що не впливає візуально, але за ним сайт знаходить повну версію зображення.

## Назви й підписи двома мовами

Поля «Підпис (англійською)» та «Підпис (українською)» — для перемикача мов. Українською показується друге поле, усіма іншими мовами (es / fr / de / en) — перше. Якщо українське поле лишити порожнім, підставиться англійське.

Назви тарифів («Скетч», «Лайнарт»…) та решта тексту сайту перекладені всередині `index.html` і через адмінку не редагуються — там тільки цифри.

## Дрібниці

- Якщо відкрити `index.html` подвійним кліком з диска, браузер заблокує читання `data/*.json`, і сайт покаже вбудовану копію вмісту. Це нормально — на живому сайті читаються саме файли з `data/`.
- Шрифти підтягуються з Google Fonts, тож перше відкриття потребує інтернету.
- Тека `admin/` закрита від пошукових систем через `noindex`.
